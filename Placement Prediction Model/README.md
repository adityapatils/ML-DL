# Placement Prediction Model

This project predicts if a student will get placed based on their **CGPA** and **IQ**. We use a logistic regression model to classify students based on these features.

## Project Overview

The project includes the following steps:

1. **Data Preprocessing**: Loading the data and cleaning it for analysis.
2. **Feature Scaling**: Standardizing features for optimal model performance.
3. **Model Training**: Training a logistic regression model.
4. **Evaluation**: Assessing the model’s accuracy.
5. **Deployment**: Saving the trained model for future predictions.
